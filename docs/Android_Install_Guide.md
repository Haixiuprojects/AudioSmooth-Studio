# Android install guide

1. Download `AudioSmoothStudio_Android_v1.0.0.apk` and `main.1.com.audiosmooth.studio.obb` from the [Android v1.0.0 release](https://github.com/Haixiuprojects/AudioSmooth-Studio/releases/tag/android-v1.0.0).
2. Install the APK. If Android asks, allow your chosen file manager/browser to install apps from that source.
3. Keep the `.obb` in Downloads. Do not extract or rename it.
4. Open AudioSmooth Studio and tap **Choose offline model pack**.
5. In the Android file picker, open Downloads and select `main.1.com.audiosmooth.studio.obb`.
6. Wait for the index/model verification to finish, then select an audio file and workflow.

The `.obb` is AudioSmooth's custom `ASOBB1` sidecar, not a standard Android expansion-file mount. Do not put it in `Android/obb`.
